## Secure administration and durable content
- [ ] `/admin` is private and authentication-protected, with persistent supported sessions, logout, protected server-side operations, and no public visitor access. Do not hardcode production passwords/API keys or expose secrets in browser code. Do not permit public administrator account creation.
- [ ] Administrators can add/edit/delete releases (confirm before delete), upload/change cover artwork, edit title/artist/slug/description/genre/date/type, manage and reorder streaming links, set featured, publish/unpublish, save drafts, preview before publication, manage artist profiles, edit homepage/label content, social links and contact details.
- [ ] All administrative changes persist in the database and appear on public pages after publication without source edits. Use related persistent data for releases, artists, platform links, settings and admin authorization. Public users read only published release fields; writes are restricted to authorized admins; validate server-side; keep migrations/schema reproducible; secure artwork storage; never expose a service-role secret.
- [ ] The requested content is backed by durable managed MySQL (the supported provisioned database if Supabase is unavailable), not browser localStorage alone. Use an appropriate first-administrator bootstrap procedure and document it without a hardcoded password.

## Contact, legal and rights
- [ ] `/contact` provides name, email, subject and message fields with validation, loading/success/error states and spam protection. Submit to a real backend/email integration; do not display a fake success. Persist successful submissions to an administrator-only inbox. If delivery credentials are absent, explain the setup clearly and provide an actual alternative contact link only if the owner configures an address; never invent the label email.
- [ ] `/privacy` explains contact-form information, use, retention and deletion requests without claiming unverified legal compliance.
- [ ] `/terms` provides editable website-use terms, notes streaming services have their own terms, and never transfers artist music ownership to the label.
- [ ] `/rights` explains that music rights depend on applicable ownership/licensing agreements, that artists retain master ownership unless a separate written agreement provides otherwise, and the label only distributes/promotes recordings with obtained rights and permissions. Provide a route for legitimate rights inquiries/takedown requests. A label credit alone is not a claim of ownership.
